⚡ Response actions — tiered automation
Triagle tiers containment by blast radius. Reversible, low-impact actions on confirmed-malicious indicators run automatically so the attacker loses access in seconds. Anything that could disrupt production or lock out a real user — isolating a host, disabling an account — always waits for a human. Every action runs through the Action Gateway — it resolves the vendor connector (Defender / CrowdStrike / Entra / Fortinet), re-checks policy and approval, and logs a signed audit entry.
